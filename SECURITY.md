# Security Policy

Kuasar Sandbox centralizes security reporting in the project repository.

Do not disclose a suspected vulnerability in a public issue, pull request, discussion, log, or attachment. Review the current supported-version policy and submit the report through the private channel documented at:

- https://github.com/kuasar-sandbox/kuasar-sandbox/security/policy
- https://github.com/kuasar-sandbox/kuasar-sandbox/security/advisories/new

Include the affected aggregate release, component version or commit, deployment mode, impact, reproduction conditions, and sanitized supporting evidence. Do not include real customer data, active credentials, private keys, or unrelated infrastructure details.

Cross-component reports may be filed once in the project repository; maintainers will coordinate the relevant component owners.
